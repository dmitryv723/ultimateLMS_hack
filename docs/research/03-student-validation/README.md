# 03. Проверка со студентами

**Вопрос.** Какие ситуации из карты действительно возникают у других студентов и как они с ними справляются?

Начни с конкретного случая. Если разговор состоялся, зафиксируй, что человек делал, в каких каналах и чем всё закончилось. Обобщения по нескольким разговорам связывай с обезличенными заметками.

## Вопросы

1. Когда в последний раз понадобилось узнать об изменении пары, проверить учебный результат или обратиться в деканат?
2. Где ты начал искать ответ? Куда пришлось перейти дальше?
3. Где возникла задержка или потребовалась помощь?
4. Чем всё закончилось? Как часто случается похожее?

Короткие заметки можно дописать сюда. Если разговоров станет несколько, сохрани их в `notes/` внутри этапа. Выводы, которые меняют выбор сценариев, вынеси в [общую сводку](../findings.md) со ссылкой на наблюдение.

# 04. Выбор сценариев

**Вопрос.** Вокруг каких студенческих задач стоит строить конкурсный кабинет?

Кандидаты берутся из [карты и сквозных сценариев](../01-student-activity-map/README.md). Основания ищем в [разборе LMS ЦУ](../02-cu-lms-review/README.md), [разговорах со студентами](../03-student-validation/README.md) и [общей сводке](../findings.md).

В [таблице сравнения](comparison.md) сопоставь ситуации по частоте, последствиям для студента, покрытию брифа и реализуемости до дедлайна. При слабых основаниях укажи, что именно нужно проверить перед выбором.

[Оценка охвата LMS](lms-coverage.md) описывает возможный результат, ограничения и зависимости для процессов студентов и сотрудников.

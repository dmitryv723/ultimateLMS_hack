# 01. Карта студенческих действий

**Вопрос.** Какие задачи студент решает от первых недель после зачисления до выпуска?

**Охват.** Очный бакалавриат российского вуза. Учёба, административные вопросы и жизнь кампуса. Для шагов, которые зависят от конкретного вуза, указываем это явно.

Готова [обзорная карта](map.md) с 13 областями, детализацией действий и переходами. В [сквозных сценариях](cross-area-scenarios.md) собраны пять маршрутов между сервисами. Для воспроизведения есть [исследовательский промпт](prompt.md).

[Основания карты](sources.md) — откуда взялись области и какие позиции ещё предстоит проверить.

Следующий шаг — сверить карту с собственным опытом и собрать вопросы для разбора LMS. По мере роста карты подробности отдельных областей можно вынести в `areas/`.

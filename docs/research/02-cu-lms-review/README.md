# 02. Разбор LMS ЦУ

**Вопрос.** Что в знакомом кабинете помогает студенту выполнить задачу и в каких случаях приходится переходить в другие каналы?

Для каждого [разбора](walkthroughs.md) запиши задачу студента, реальные шаги, каналы, полезные решения и затруднения. Если из наблюдения получился переносимый принцип, добавь его в [копилку решений](patterns.md).

Записывай наблюдения своими словами и убирай личные сведения, внутренние ссылки с токенами и закрытые материалы вуза.

## Как запустить

1. Установи Node.js 24. Здесь проверяли на Node.js 24.14.1. Это нативный Node HTTP, SQLite из node:sqlite, серверные HTML-шаблоны, CSS и небольшой клиентский JS. Сторонних npm-зависимостей нет.
2. В корне выполни `npm test`. Тесты используют HTTP-обработчик приложения и изолированные базы. Базовый результат — 26/26.
3. Выполни `npm run demo:accounts`. На новой базе команда создаёт учётные записи и выводит пароли. Храни их отдельно. Логины студентов — anna, daria, maksim; сотрудников — teacher и office. Команда с `-- --reset` меняет существующие демопароли, поэтому для проверки на чистых данных выбери отдельную базу. Одноразовое восстановление — `npm run accounts:reset-code -- anna`.
4. Выполни `npm start` и открой http://127.0.0.1:3000. Для прежнего порта на PowerShell перед запуском выполни `$env:PORT = '3100'`. В Linux можно использовать `PORT=3100 npm start`.
5. База по умолчанию — .local/dean.sqlite. Переменная DEAN_DB_PATH меняет путь. Создание аккаунтов, запуск и восстановление пароля должны использовать одну и ту же базу. Анна и Дарья — БА-24, Максим — МО-23. teacher ведёт «Прикладную статистику» и «Микроэкономику» у БА-24. office управляет расписанием всех групп и видит все обращения; преподавателю расписание групп недоступно.
6. `npm run preview -- .local/lms-courses-preview.html` создаёт отдельный студенческий HTML-предпросмотр. Для SQLite, авторизации и межролевых путей используй приложение через HTTP.

Порт 3100 из предыдущей среды автоматизации не отвечал. Последние доработки проверялись маршрутными тестами. При переносе перепроверь живой браузер, особенно ширину 360 px. Пройди под разными аккаунтами вход, ближайшую пару и перенос, оценку, подачу и статус справки, объявление и недоступность чужих карточек.

## Следующая итерация — готовая справка

Студент подаёт заявку на электронную справку. Сотрудник открывает заполненную заявку, прикладывает готовый документ и переводит в «Готово». Студент получает уведомление, открывает карточку и скачивает приложенный документ. PDF можно взять за формат первой версии, если владелец не обозначит другой. Бумажная выдача, смешанный формат и ранее созданные заявки требуют отдельной проверки.

- app/staff-routes.js и app/staff.js — карточка офиса, смена статуса и комментарии.
- app/server.js — проверка роли и CSRF, обработка multipart, скачивание. Сейчас маршрут справки выдаёт демонстрационный TXT.
- app/services.js — формы студента, модель доставки, карточка и текст демонстрационной справки.
- app/store.js — данные обращения, транзакция статуса и комментария. Пригодные примеры загрузок и хранения смотри в app/publication.js, app/homework-store.js, app/event-store.js.
- app/notifications.js и app/account-notifications.js — уведомления. app/test/routes.test.js — существующие проверки приватности, статусов и загрузок.

Приёмка. Файл сохраняется после перезапуска, скачивается из своей заявки и остаётся закрытым для другого студента по прямой ссылке. У сотрудника без прав нет доступа к изменению или выдаче. Ошибка загрузки или конфликт статуса не должны оставлять электронную заявку в состоянии «Готово» без ожидаемого файла. Повторная отправка не создаёт дубли. Старые заявки продолжают открываться. Демонстрационный образец явно подписан, если он нужен для старых сценариев. Добавь маршрутный тест.

Даты сессии, индивидуальные результаты и объявления были тремя ближайшими Must и уже реализованы. Базовый FAQ из Should тоже сделан. После справки сверяй приоритеты заново. Оставшиеся кандидаты — актуализация содержания силлабусов, онлайн-ссылка из карточки пары, порядок действий при пропуске и ручная проверка основных сценариев на телефоне. Полноценные процессы практики, жилья, платежей и выпуска исходно отложены.

## Деплой и конкурсная сдача

В отдельном разговоре владелец обсуждал российский VPS и SSH. Завершённый деплой и доступ к VPS не подтверждены. Старые административные реквизиты и адреса доступа в архиве отсутствуют. При новой задаче по деплою выясни текущий сервер, домен или согласованный адрес HTTPS, состояние уже работающих служб и используемую БД. Для доступа используй отдельно переданный SSH-ключ или иной согласованный способ.

Стенд ожидает Node.js 24, постоянный DEAN_DB_PATH, loopback-порт PORT и HTTPS-прокси с сохранением публичного Host. DEAN_PUBLIC_ORIGIN — публичный HTTPS origin без пути. Для демонстрации проверь два студенческих аккаунта и нужные роли на опубликованной версии из России без VPN. На сдачу требуются ссылка, демонстрационные доступы, исходники и описание процесса со скриншотами; подаёт капитан. Деплой, push и отправка конкурсной работы выполняются по отдельной команде владельца.

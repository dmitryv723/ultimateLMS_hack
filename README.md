# Цифровой деканат будущего

Конкурсный прототип студенческого кабинета для номинации «Вайб-кодинг» MGIMO AI Challenge 2026. Кабинет объединяет расписание, курсы и сроки, успеваемость, справки, обращения и уведомления. В рабочих интерфейсах преподаватель публикует материалы, проверяет работы и предлагает переносы, а учебный офис обрабатывает обращения, выдаёт готовые справки файлом и ведёт расписание, сессию и объявления.

## Локальный запуск

Нужен Node.js 24. Данные по умолчанию сохраняются в `.local/dean.sqlite`.

```powershell
npm run demo:accounts
npm start
```

Откройте [локальный кабинет](http://127.0.0.1:3000). Команда инициализации выводит пароли для новых демонстрационных учётных записей. Логины студентов — `anna`, `daria` и `maksim`, сотрудников — `teacher` и `office`.

Для восстановления запустите `npm run accounts:reset-code -- <логин>` в той же конфигурации базы. Код вводится на странице «Сбросить пароль». Он действует 30 минут и используется один раз.

`npm test` запускает сценарии через обработчик HTTP. `npm run preview -- .local/lms-courses-preview.html` экспортирует интерактивный студенческий HTML из тех же шаблонов и стилей.

## Стенд и конкурсная сборка

Для стенда приложение запускается за HTTPS-прокси с сохранением публичного заголовка Host. Задайте `DEAN_PUBLIC_ORIGIN` как HTTPS origin без пути и `DEAN_DB_PATH` как путь к постоянной базе SQLite. Процесс слушает loopback, порт задаётся через `PORT`.

# Цифровой деканат будущего

Конкурсный прототип студенческого кабинета для номинации «Вайб-кодинг» MGIMO AI Challenge 2026. Кабинет объединяет расписание, курсы и сроки, успеваемость, справки, обращения и уведомления. В рабочих интерфейсах преподаватель публикует материалы, проверяет работы и предлагает переносы, а учебный офис обрабатывает обращения и ведёт расписание, сессию и объявления.

# Промпт для новой нейросети

Распакуй приложенный ZIP в отдельную папку. Открой START-HERE.md, PROJECT-HANDOFF.md и AGENTS.md. Продолжай существующий проект «Цифровой деканат будущего» для MGIMO AI Challenge. В архиве актуальная рабочая копия, включая код, которого может не быть в GitHub.

Проверь Node.js 24 и запусти npm test. На момент передачи проходили 26 тестов. Для браузера создай отдельную демонстрационную базу по инструкции в PROJECT-HANDOFF.md. Работай на русском языке, в существующем приложении с HTML, CSS и SQLite.

Мы остановились после реализации публикации объявлений учебным офисом для выбранной группы или курса. Если я попрошу продолжить по приоритетам, следующая задача — выдача готовой справки из карточки обращения. Критерии и точки входа есть в PROJECT-HANDOFF.md.

Развивай согласованный сценарий до проверки. Если команда или подключение зависли, сразу скажи, в чём проблема, и продолжай доступные шаги. Секреты и локальная база передаются отдельно. Деплой, push и конкурсная отправка — отдельные задачи по моей команде.
